🔥 PROJETO FÊNIX — S23 WINDOWS ARM

Uma nova vida para o hardware.

O Projeto FÊNIX é uma iniciativa independente de pesquisa e desenvolvimento experimental que busca investigar a possibilidade de executar Windows ARM nativamente no Samsung Galaxy S23.

🎯 NOSSA MISSÃO

Investigar e desenvolver uma solução para inicializar Windows ARM diretamente no hardware do Galaxy S23, buscando substituir completamente o Android.

Não buscamos virtualização, emulação ou acesso remoto.

📱 HARDWARE DE REFERÊNCIA

Componente| Especificação
Dispositivo| Samsung Galaxy S23
Modelo| SM-S911B
Codinome| dm1q
Processador| Snapdragon 8 Gen 2
SoC| SM8550
GPU| Adreno 740
Memória RAM| 8 GB

🔬 ÁREAS DE PESQUISA

- Bootloader e cadeia de inicialização.
- UEFI / EDK2.
- Qualcomm SM8550.
- Drivers de hardware.
- GPU e gerenciamento de vídeo.
- Tela e touchscreen.
- Armazenamento.
- Áudio, Wi-Fi e Bluetooth.
- Compatibilidade com Windows ARM.

📊 ESTADO ATUAL

O projeto está em fase inicial de investigação. Ainda não temos uma inicialização funcional do Windows ARM comprovada neste aparelho.
